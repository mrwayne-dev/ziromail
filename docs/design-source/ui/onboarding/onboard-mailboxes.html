There is no seat limit

Create as many mailboxes as you like. The pool is the only limit — ten people sharing 30 GB is fine if their quotas add up.

Start small

Give each person a little less than you think. Raising a quota takes two seconds later; you cannot lower one below what a mailbox already holds.

Leave some unassigned

Storage you do not hand out stays in the pool, ready for a new hire or a mailbox that fills faster than expected.

Shared addresses cost nothing

An address like info@ that just forwards into an existing mailbox is not a mailbox and uses no storage of its own. Add those from the dashboard afterwards.
