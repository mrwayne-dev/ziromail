Alias or forwarding?

An alias is another name for one mailbox — replies come from the main address. Forwarding copies mail to several mailboxes, which suits a shared address like info@.

Catch-all is off

A catch-all accepts mail to any address at your domain, including ones that do not exist. It attracts a great deal of spam, so we leave it off. Turn it on only if you genuinely need it.
